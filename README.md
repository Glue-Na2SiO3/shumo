## 说明

- **个人作品**目录保留了每篇论文的成品 PDF / Word、建模代码与支撑材料，可直接参考结构与写法。
- **备赛资料库**来自公开培训资料的整理归档；受 GitHub 单文件 100MB 限制，原始大容量压缩包（历年优秀论文合集 zip、教材 rar、软件安装包）未入库，仅保留解压后的课件、代码与论文。
- LaTeX 中间文件（`.aux/.log/.toc/.synctex.gz` 等）已通过 `.gitignore` 忽略，仓库中只保留 `.tex/.cls/.pdf` 源文件与成品。
