# 问题 1：抽样检测方案设计与求解

## 一、问题重述

企业对供应商提供的零配件（零配件 1 或 2 ）开展抽样检测，需设计检测次数最少的抽样方案，判别其次品率是否超标称值 10% ，满足：在 95% 信度下，若判定次品率超 10% 则拒收；在 90% 信度下，若判定次品率不超 10% 则接收。

## 二、问题分析

### （一）核心矛盾

平衡抽样成本（检测次数）与决策可靠性（信度要求），以最小样本量实现对次品率的统计推断。

### （二）统计推断逻辑

- **假设设定**：原假设 \($H_0$\) 为次品率 \($p \leq 10\%$\)（合格批）；备择假设 \($H_1$\) 为次品率 \($p > 10\%$\)（不合格批）。要求 \($H_0$\) 为真时，接收概率≥90%（防错拒合格批）；\($H_1$\) 为真时，拒收概率≥95%（防错收不合格批）。
- **关键参数**：标称值 \($p_0 = 0.1$\)（\($H_0$\) 边界）；参考超标值 \($p_1$\) ，依国际电工委员会（IEC）推荐，取 \($p_1 = 1.5\times p_0 = 0.15$\)（平衡检验灵敏度与样本量需求）；错拒概率上限 \($\alpha = 0.1$\)（对应接收合格批信度≥90% ），错收概率上限 \($\beta = 0.05$\)（对应拒收不合格批信度≥95% ）。

## 三、模型建立

### （一）抽样分布模型

设样本量为 n ，检测出的不合格品数为 d ，d 服从二项分布 \($d \sim B(n, p)$\)（p 为实际次品率 ），二项分布概率质量函数为：\($P(X = k) = \binom{n}{k} p^k (1 - p)^{n - k}$\) 其中 \($\binom{n}{k} = \frac{n!}{k!(n - k)!}$\) ，表示从 n 次独立试验中选 k 次 “成功”（此处 “成功” 指检测到不合格品 ）的组合数。

### （二）决策规则

设定临界值 c ，若 \(d < c\) ，接收该批（判定 \($p \leq 10\%$\) ）；若 \($d \geq c$\) ，拒收该批（判定 \($p > 10\%$\) ）。

### （三）约束条件

1. **合格批接收约束**：当 \($p = p_0 = 0.1$\)（合格批 ），接收概率需满足：\($P(d < c \mid p = p_0) \geq 1 - \alpha = 0.9$\) 即二项分布 \($B(n, p_0)$\) 中，不合格品数小于 c 的概率不低于 90% ，用累积分布函数（CDF）表示为：\($\sum_{k = 0}^{c - 1} \binom{n}{k} p_0^k (1 - p_0)^{n - k} \geq 0.9$\)
2. **超标批拒收约束**：当 \($p = p_1 = 0.15$\)（超标批 ），拒收概率需满足：\($P(d \geq c \mid p = p_1) \geq 1 - \beta = 0.95$\) 等价于不合格品数小于 c 的概率不高于 5% ，即：\($\sum_{k = 0}^{c - 1} \binom{n}{k} p_1^k (1 - p_1)^{n - k} \leq 0.05$\)

### （四）优化目标

最小化样本量 n ，即：

$\min_{n \in \mathbb{N}^+, c \in \{0, 1, \dots, n\}} n$

$\text{s.t.} \begin{cases} \sum_{k = 0}^{c - 1} \binom{n}{k} p_0^k (1 - p_0)^{n - k} \geq 0.9 \\ \sum_{k = 0}^{c - 1} \binom{n}{k} p_1^k (1 - p_1)^{n - k} \leq 0.05 \end{cases}$

## 四、模型求解

### （一）求解方法：枚举法

遍历可能的样本量 n（从 1 开始逐步增大 ）和临界值 c（从 0 到 n ），验证每个 \((n, c)\) 组合是否满足约束条件，步骤如下：

1. 对每个 n ，遍历 \($c = 0, 1, \dots, n$\) ；
2. 计算合格批接收概率：当 \(c = 0\) 时，因不合格品数小于 0 不可能，接收概率为 0；否则，用二项分布累积分布计算 \($\sum_{k = 0}^{c - 1} \binom{n}{k} p_0^k (1 - p_0)^{n - k}$\) ；
3. 计算超标批拒收概率：当 \(c = 0\) 时，不合格品数大于等于 0 必然，拒收概率为 1；否则，计算 \($1 - \sum_{k = 0}^{c - 1} \binom{n}{k} p_1^k (1 - p_1)^{n - k}$\) ；
4. 若满足合格批接收概率≥90% 且超标批拒收概率≥95% ，记录此时的 n 和 c ，继续寻找更小的 n 。

### （二）求解结果

经枚举计算，最优解为：

- 样本量 \(n = 379\) ，临界值 \(c = 46\) 。
- 验证指标：
  - 当 \($p = p_0 = 0.1$\) 时，合格批接收概率 \($\sum_{k = 0}^{45} \binom{379}{k} 0.1^k (1 - 0.1)^{379 - k} = 0.9011$\)（≥90% ），错拒概率 \(1 - 0.9011 = 0.0989\)（≤10% ）；
  - 当 \(p = p_1 = 0.15\) 时，超标批拒收概率 \($1 - \sum_{k = 0}^{45} \binom{379}{k} 0.15^k (1 - 0.15)^{379 - k} = 0.9520$\)（≥95% ），错收概率 \(1 - 0.9520 = 0.0480\)（≤5% ），均满足约束。

## 五、结果分析

### （一）操作特性（OC）曲线

OC 曲线横轴为实际次品率 p ，纵轴为接收概率。对 \(p \in [0, 0.3]\) 取 200 个点，计算每个 p 对应的接收概率（即 \($\sum_{k = 0}^{45} \binom{379}{k} p^k (1 - p)^{379 - k}$\) ）并绘制曲线（如图 1 ）。曲线特点：

- 当 \($p \leq 0.1$\) ，接收概率稳定在 90% 以上，契合 “高信度接收合格批” 要求；
- 当 \($p \geq 0.15$\) ，接收概率降至 5% 以下，满足 “高信度拒收不合格批” 需求；
- p 在 \(0.1\) 到 \(0.15\) 间，曲线快速下降，体现对次品率变化的灵敏区分度。

### （二）方案可行性

样本量 379 平衡了统计可靠性与检测成本。电子产品零配件检测中，该样本量能有效控制错判风险，又不会因检测次数过多导致成本过高，具实际应用价值。

## 六、结论

针对标称次品率 10% 的零配件，最优抽样检测方案为：抽取 379 个样本检测，不合格品数小于 46 则以 90% 信度接收，≥46 则以 95% 信度拒收。方案依 IEC 推荐设参数，借严格统计约束保决策可靠，同时最小化检测次数，适配企业零配件采购质量控制需求。
